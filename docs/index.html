Documentation

Desktop app

  1. Download and install the package for your operating system.
  2. Open the app and paste your ElevenLabs API key.
  3. Drop one or more MP3 files, then press Run.

Windows and Linux Mint

Windows: keep the executable and its _internal folder together after extracting. Builds are unsigned, so Windows may display a publisher warning.

Linux Mint: the installer adds required system libraries and GNOME Keyring. Unlock your login keyring in Passwords and Keys if the API key cannot be saved. Mint 20, LMDE, and ARM devices are not supported by this package.

For updates, download the newer ZIP or DEB from this page. Your settings and transcript history stay in your user profile.

Outputs

The desktop app writes deliverables beside each source file or into the output folder you choose. The browser version downloads files directly.

Privacy

Audio is uploaded to ElevenLabs for transcription. Verify generated captions before relying on them, especially for published or regulated content.
